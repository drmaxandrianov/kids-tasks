# Домашние задания — веб-приложение

Веб-приложение для организации системы ежедневных заданий детей с накоплением баллов.

## 🚀 Возможности

- **Для родителей**: создание заданий, назначение штрафов, настройка наград, просмотр архива
- **Для детей**: просмотр заданий, отметка выполнения, отслеживание прогресса
- **Игровая механика**: животные-персонажи, прогресс-бар, система баллов
- **Еженедельный цикл**: сброс баллов каждый понедельник

## 📦 Технологии

- **Frontend**: React 18, TypeScript, Tailwind CSS, Vite
- **Backend**: Node.js, Express
- **Хранение данных**: JSON-файл (data.json)

## 🛠️ Локальный запуск

### Разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (только frontend)
npm run dev
```

### Production

```bash
# Сборка
npm run build

# Запуск сервера
node server.js
```

Приложение будет доступно на `http://localhost:3000`

## 🌐 Деплой на Amvera.ru

### 1. Регистрация

1. Зарегистрируйтесь на [amvera.ru](https://amvera.ru/)
2. Создайте проект типа **"Приложение"**
3. Выберите тариф (пробный — 170 ₽/мес)

### 2. Загрузка кода

**Вариант A — Через Git (рекомендуется):**

```bash
git init
git remote add amvera https://git.msk0.amvera.ru/<USERNAME>/<PROJECT>
git add .
git commit -m "Initial commit"
git push amvera master
```

**Вариант B — Через интерфейс:**
Откройте вкладку "Репозиторий" и перетащите файлы (без `node_modules` и `dist`)

### 3. Конфигурация

Файл `amvera.yml` уже настроен:
- Сборка: `npm install && npm run build`
- Запуск: `node server.js`
- Порт: определяется переменной окружения `PORT`

### 4. Домен

1. Откройте вкладку **"Домены"**
2. Добавьте бесплатный домен или привяжите свой
3. HTTPS включается автоматически

## 📱 Использование

### Первый вход

**Родитель:**
- Логин: `admin`
- Пароль: `admin`
- ⚠️ Сразу измените пароль в настройках!

**Дети:**
- Логин: имя ребёнка (в нижнем регистре)
- Пароль: задаёт родитель при создании профиля

### Структура данных

Все данные хранятся в файле `data.json` на сервере:
- Пользователи (родитель и дети)
- Библиотека заданий
- Назначенные задания по дням
- Штрафы
- Настройки (логин/пароль родителя, пороги наград)
- Выбранные аватары детей

## 🔒 Безопасность

⚠️ **Важно**: Приложение использует простую аутентификацию. Для продакшена рекомендуется:
- Изменить пароль администратора
- Настроить HTTPS (включено автоматически на Amvera)
- Регулярно делать бэкапы `data.json`

## 📊 Структура проекта


## 💡 Особенности

- **Серверное хранение**: данные доступны с любого устройства
- **Автосохранение**: изменения сохраняются сразу
- **Адаптивный дизайн**: работает на телефонах, планшетах, ПК
